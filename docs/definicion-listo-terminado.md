# Definition of Ready y Definition of Done

## Definition of Ready (lista para empezar)

Una historia puede pasar a "Listo" cuando:

- [ ] tiene criterios de aceptación escritos y verificables
- [ ] está estimada
- [ ] no depende de una tarea sin terminar
- [ ] sus reglas de validación o datos necesarios están definidos

## Definition of Done (terminada)

Una historia pasa a "Hecho" cuando:

- [ ] el código está en `main` mediante un pull request revisado
- [ ] las pruebas de la historia pasan (`go test ./...` y `npm test`)
- [ ] cada criterio de aceptación está comprobado y registrado
- [ ] cumple lo básico de accesibilidad: etiquetas en campos, contraste, navegación por teclado, foco visible
- [ ] no hay secretos ni datos personales reales en el código
- [ ] la bitácora está actualizada
